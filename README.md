# Автотесты для интернет-магазина

Проект с автоматизированными тестами для интернет-магазина
[selenium1py.pythonanywhere.com](http://selenium1py.pythonanywhere.com/).

## Что проверяется

- Добавление товара в корзину со страницы товара.
- Совпадение названия товара в сообщении о добавлении с названием на странице товара.
- Совпадение стоимости корзины с ценой добавленного товара.
- Работа промо-акций через параметр 
- Обнаружен и задокументирован баг на промо-акции `offer7`

## Структура проекта

```text
my_test/
├── pages/
│   ├── __init__.py         # инициализация пакета
│   ├── base_page.py        # базовый класс Page Object
│   ├── locators.py         # локаторы элементов страницы товара
│   └── product_page.py     # Page Object страницы товара
├── conftest.py             # фикстура browser (открывает/закрывает Chrome)
├── test_product_page.py    # тест-кейсы для страницы товара
├── requirements.txt        # зависимости проекта
└── README.md
```

## запуск
```bash
# прогнать все тесты
python -m pytest -s test_product_page.py
